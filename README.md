Netflix Movies and TV Shows Data Cleaning
Project Overview
This project focuses on cleaning and preparing the Netflix titles dataset for analysis.
Dataset
The dataset contains information about Netflix movies and TV shows, including:
Title
Director
Cast
Country
Release year
Rating
Duration
Genre
Description
Data Cleaning
The dataset was cleaned using Python and Pandas. The cleaning process included checking and handling missing values, removing unnecessary data, and preparing the dataset for further analysis.
Files
netflix_titles.csv — Original dataset
cleaned_netflix_titles.csv — Cleaned dataset
README.md — Project documentation
Tools Used
Python
Pandas
Jupyter Notebook
Result
The cleaned dataset is ready for further analysis and visualization.
